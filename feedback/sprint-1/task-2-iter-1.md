### РЕКОМЕНДАЦИИ 💡

1) В роутах можно использовать

Route::prefix('/auth')->group(function () {

Route::post('/register', ...

Route::post('/token', ...

});

2) api_version лучше хранить в конфиге(api.php)  или в .env

3) Валидацию нужно выносить в отдельный класс, например RegisterRequest, тогда код будет

public function register(RegisterRequest $request)

{

// Валидация данных

$request->validated();

// Создание пользователя

$user = User::create([

'name' => $request->name,

'email' => $request->email,

'password' => Hash::make($request->password),

]);

4) перед генерацией нового токена можно удалять все старые

// Удаляем старые токены

$user->tokens()->delete();
